The Persistence of Memory

Artist: Salvador Dalí

Year: 1931

The Persistence of Memory is a famous surrealist painting by Salvador Dalí. The artwork features melting clocks in a mysterious landscape, showing the idea that time can feel different and change according to our experiences.
